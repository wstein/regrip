# Test coverage

The generated reports show statement, branch, function, and line coverage for the two Vitest
suites. They are observational baselines; the build does not enforce percentage thresholds.

## Reports

- <a href="./app/index.html">Regrip Console and integration coverage</a>
- <a href="./core/index.html">Published core package coverage</a>

Run `npm run test:coverage` locally to regenerate both reports. The complete site build generates
them automatically before VitePress packages the documentation.
