Getting started

Open the lab in a Bluetooth-capable browser, click Connect, and pick your cube from the system pairing dialog. No install, no account.

Connecting a cube

The adapter negotiates the device's protocol automatically. Once connected, the panel on the right reports capabilities, firmware and battery. 

const cube = await Regrip.connect();
console.log(cube.protocol); // "gocube"
Events

Every move, facelet update, gyro reading and regrip is emitted as a typed event on the trace stream.

Field Type Description
type string move · event · state · gyro · regrip
recordedAt ISO 8601 Timestamp the lab received the event
data object Payload — shape depends on type
Moves API

Moves are reported in standard cube notation (U, U', F, F2 …) and can be simplified to remove cancelling turns before export.

Protocols

GoCube and GAN12 UI are supported today; a JSONL mock protocol lets you replay a recorded trace without hardware.
