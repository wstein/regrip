Getting started

Open the lab in a Bluetooth-capable browser, click Connect, and pick your cube from the system pairing dialog. No install, no account.

Connecting a cube

The lab negotiates the device's protocol automatically. Once connected, the panel on the right reports the selected adapter, capabilities, firmware, and battery. Regrip is an application rather than a browser SDK: use the lab's Connect control or the generated TypeScript API reference for its internal integration boundaries.

Events

Every move, facelet update, gyro reading and regrip is emitted as a typed cube event on the trace stream. These events alone can update cube state and are captured for replay.

Field Type Description
type string move · event · state · gyro · regrip
recordedAt ISO 8601 Timestamp the lab received the event
data object Payload — shape depends on type
Diagnostics

The default-off Diagnostic trace filter exposes optional packet-decoder evidence without treating it as cube state. Diagnostic packets are held in a separate bounded buffer and never enter move tracking, facelet reconciliation, triggers, or the normal JSONL replay capture.

Protocol family Diagnostic evidence
GoCube Plaintext raw frames and malformed-frame reasons
GAN Decoded frames and validation failures; encrypted wire bytes are omitted
MoYu32 Decoded opcode frames and unknown-opcode reports; encrypted wire bytes are omitted
Giiker / MoYu MHC Plaintext frames and malformed-frame reasons
QiYi Unknown decoded packets

Packet kinds are RAW_PACKET, DECODED_PACKET, MALFORMED_PACKET, and UNKNOWN_PACKET. A valid decoded packet still produces its normal typed cube event; an unknown packet remains diagnostic-only.

Moves API

Moves are reported in standard cube notation (U, U', F, F2 …) and can be simplified to remove cancelling turns before export.

Protocols

Six adapters cover GAN, GoCube, Giiker, MoYu MHC, MoYu32, and QiYi cubes. A JSONL mock adapter lets you replay a recorded trace without hardware.
