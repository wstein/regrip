# Security policy

## Reporting a vulnerability

Please do not disclose vulnerabilities publicly before a fix is available. Use GitHub's private
repository reporting feature when it is enabled; otherwise contact the repository owner privately
through GitHub with a minimal reproduction.

Do not include device MAC addresses, serial numbers, unredacted JSONL captures, credentials, or
personal information in a public issue or proof of concept.

## Scope

This project is a browser demo that uses Web Bluetooth. Reports involving unsafe device commands,
unexpected Bluetooth permissions or connections, data exposure, dependency supply-chain risks,
or code execution are in scope.

Maintainers will acknowledge a valid report, investigate it, coordinate a fix, and credit the
reporter if they wish.
