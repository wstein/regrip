## smartcube-sample

This is simple one-page application which uses the [smartcube-web-bluetooth](https://github.com/poliva/smartcube-web-bluetooth) library.
It demonstrates the Generic Smart Cube API, which automatically detects and connects to supported GAN, Giiker, GoCube, MoYu, and QiYi smart cubes.
Demo includes approach to proper time measurement and gyroscope event handling.

Compiled live version of this application is available here:
 
 - https://afedotov.github.io/smartcube-sample/
